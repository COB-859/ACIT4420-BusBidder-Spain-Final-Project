BusBidder Spain is a simulated marketplace for bus journeys from Madrid. It reads offers from five fictional bus companies, removes the offers a traveller cannot accept, ranks the rest with a weighted score, explains the top offer and simulates a booking.

This file is a stub. It is completed in the last build step.

## Requirements

- Python 3.10 or later
- No third-party packages

## Running

Run all commands from this folder (the one that holds `main.py`).

```bash
python3 main.py --help
```

On Windows, or any system where the command is `python`:

```bash
python main.py --help
```

## Tests

python3 -m unittest discover -s tests -t . -v
